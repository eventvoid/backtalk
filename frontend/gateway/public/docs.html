API modes

Three ways to reach the same models. Pick by who's calling.

ModeForAccessFeedbackStreaming
webThis website (Ask / Stories)Site only — no key, can't be used off-siteYes (Yes/No or A/B)Yes
openaiThird-party clients via any OpenAI SDKOpen — API key optionalNoYes (SSE)
nativeBackTalk's own APIOpen — API key optionalNoNo (single JSON)

API keys are optional for openai and native (anonymous callers are rate-limited by IP; a key raises/identifies your limits). web needs nothing but only works on this site, and it's the one mode with feedback.

OpenAI-compatible API

Point any OpenAI SDK at …/v1. Any non-empty api_key works.

curl __BASE__/v1/chat/completions \
  -H "authorization: Bearer $OPENAI_KEY" -H 'content-type: application/json' \
  -d '{"model":"backtalk-assistant","messages":[{"role":"user","content":"Why is the sky blue?"}]}'
# pip install openai
from openai import OpenAI
client = OpenAI(base_url="__BASE__/v1", api_key="$OPENAI_KEY")
print(client.chat.completions.create(
    model="backtalk-assistant",
    messages=[{"role":"user","content":"Why is the sky blue?"}],
).choices[0].message.content)
// npm i openai
import OpenAI from "openai";
const client = new OpenAI({ baseURL: "__BASE__/v1", apiKey: process.env.OPENAI_KEY });
const r = await client.chat.completions.create({
  model: "backtalk-assistant",
  messages: [{ role: "user", content: "Why is the sky blue?" }],
});
console.log(r.choices[0].message.content);

Native API

BackTalk's own API with moderate limits and concurrent requests. Single answer, no feedback. The authorization header is optional.

curl __BASE__/api/v1/generate \
  -H 'content-type: application/json' \
  -d '{"model":"backtalk-assistant","prompt":"Why is the sky blue?"}'
# optional: -H "authorization: Bearer $NATIVE_KEY" for higher/identified limits
# pip install requests
import requests
r = requests.post("__BASE__/api/v1/generate",
    json={"model": "backtalk-assistant", "prompt": "Why is the sky blue?"}).json()
print(r["output"])

Limits

Limits apply per API key, or per IP for anonymous callers. Concurrent is how many requests one caller may run at once. Over a limit → a clear error; the queue is never blocked. Backend nodes accept unlimited concurrency — the gateway spreads load across them by how busy each is and its tokens/sec, and only returns server is busy, try again later when no node is online.

Feedback & data

Feedback is available on web only. One answer → Yes / No; two answers → A / B / None. Every request + answer + your choice is logged for future training (admins can export it as JSONL).

Models

List with GET /web/models (or /api/v1/models, /v1/models). Bare ids track the newest version; pin one with backtalk-assistant-v2 / -v1.
